# 有道背单词纯净词库 (ydschool_dict)

本目录为从网易**有道背单词（移动端）**官方接口拉取的全量英语词库，并由本地 Python 脚本自动化下载、解析、系列合并与去重，生成**最纯净、最轻量**的逐行纯单词文本（`.txt`）。

---

## 🌟 核心特性

- **极致纯净**：每行仅包含一个英文单词或短语，去除音标、中文释义、例句、测试题等所有冗余内容，文件体积仅为几十 KB，极度轻巧便携。
- **系列教材完整合并**：
  - **人教版小学英语**（3年级上册 ~ 6年级下册，共 8 册）合并为 `人教版小学英语.txt`。
  - **人教版初中英语**（7年级上册 ~ 9年级全册，共 5 册）合并为 `人教版初中英语.txt`。
  - **外研社版初中英语**（7年级上册 ~ 9年级下册，共 6 册）合并为 `外研社版初中英语.txt`。
  - **人教版高中英语**（必修 1~5 + 选修 6~11，共 11 册）合并为 `人教版高中英语.txt`。
  - **北师大版高中英语**（必修 1~5 + 选修 6~11，共 11 册）合并为 `北师大版高中.txt`。
- **全版本互补合并**：同本书的**正序版**、**乱序版**、**图片记忆版**全量归并处理，互为补充，避免单一版本遗漏或错别字，确保词表**不重不漏**。
- **严格正序与去重**：各词表经集合全局去重后，按照字母表严格正序排列（大小写不敏感自然排序）。
- **借词规范化**：针对英语中极少量的法语借词（如 `café`、`resumé`、`cliché` 等），自动平滑转换为标准英文字母（`cafe`、`resume`、`cliche`），便于检索和匹配。

## 🚀 快速使用

根据项目规范，推荐使用 `uv` 运行：

### 1. 一键生成全部词表

在 `ydschool_dict` 目录或项目根目录下执行：

```bash
uv run python ydschool_dict/main.py
```

脚本将自动执行以下步骤：
1. 访问有道背单词接口获取全部 81 本词书列表与离线下载地址；
2. 校验本地已存在的压缩包，缺失时自动下载至 `raw_zips/`；
3. 解压并流式解析每行 JSONL 数据，提取 `headWord`；
4. 按系列与版本归并、去重、字母序排序，输出至 `ydschool_dict/book/`。

### 2. 命令行参数

- `--force-download`：强制重新从网络下载所有 81 个 ZIP 离线包。
- `--output-dir <path>`：自定义 `.txt` 输出路径（默认为 `ydschool_dict/book`）。

```bash
uv run python ydschool_dict/main.py --force-download
```

## 🛠️ 接口技术细节

有道背单词服务端 API 依然保持稳定可用：

1. **获取词书 ID 列表**：
   - URL：`GET http://reciteword.youdao.com/reciteword/v1/param?key=normalBooks`
   - 返回 JSON 数据，`data.normalBooks.bookList` 包含 81 个词书对象。
2. **获取词书下载信息**：
   - URL：`POST http://reciteword.youdao.com/reciteword/v1/getBooksInfo`
   - 携带参数：`bookIds`、`reciteType=normal` 等。
   - 返回各词书的封面图、标题、单词量以及网易对象存储下载地址 `offlinedata`。
3. **词书离线包结构**：
   - 离线包为标准 ZIP 格式，解压后为 JSON Lines 结构。
   - 每行为一个词条 JSON 对象，字段包括 `wordRank`、`headWord`、`content` 等。
   - 本项目通过 `main.py` 仅解析提取 `headWord` 字段并完成最终纯净导出。
